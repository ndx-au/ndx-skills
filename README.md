# ndx-skills

Cursor skills we built over time. Each skill is a folder under `.cursor/skills/` (`SKILL.md` plus any scripts). Clone this repo, or symlink a skill into `~/.cursor/skills/`.

- [`ndx-gauntlet`](.cursor/skills/ndx-gauntlet) — after a Cursor plan has been implemented, compose five critic lenses into one leftover plan.
